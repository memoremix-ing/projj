      Speech Mode: read the page to you from the selection, or from what is on screen where you last clicked or scrolled; again to pause (Ctrl+Shift+U off a Mac)
      
  
      
  
      Click a changed line's number to select it, or to deselect it. Shift-click does the same to every line in between. Selected lines can be marked on their own.
      
  
      Select any text in a diff to edit the file at that spot. The editor opens below the diff, so both stay in view; drag its top edge to resize it.
      
  
      The editor keeps every file you open, with its unsaved edits, until you close that file. Unsaved edits also survive hiding the editor and reloading the page; "Unsaved edits" in the editor lists them all.
